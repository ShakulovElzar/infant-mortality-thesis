# U.S. datasets adjacent to the CDC infant-death thesis

Checked 20 November 2026 against primary provider pages. The main patient-level cohort is the public [CDC/NVSS linked birth–infant death file](https://www.cdc.gov/nchs/data_access/VitalStatsOnline.htm), covering deaths before age one. These additional sources have different observation units. File sizes below are provider-listed download sizes, not analysis-table size.

## Join feasibility first

[NCHS release policy](https://www.cdc.gov/nchs/nvss/dvs_data_release.htm) says public individual vital-record files for 2005 onward contain no state/county/city or exact event dates. Thus there is **no valid individual-level join** from the current CDC cohort files to county poverty, provider supply, social vulnerability, weather or pollution. [Restricted geographic files](https://www.cdc.gov/nchs/nvss/nvss-restricted-data.htm) require proposal approval, an advisor CV/support letter for students, and are not sent to or remotely accessed from outside the U.S.; unsuitable as a March 2027 dependency for a student in Italy. The only simple direct addition to the public individual file is another variable already inside its linked birth/death records; separate U.S. natality ZIPs mostly duplicate its birth-certificate fields rather than add independent follow-up.

## Additional sources

| Source | Observation / fields | Access, size, and relation to main data |
|---|---|---|
| [CDC WONDER linked birth/infant death expanded](https://wonder.cdc.gov/lbd.html), [documentation](https://wonder.cdc.gov/wonder/help/lbd-expanded.html) | Exportable aggregated counts and rates by year, state, identified county, maternal demographics/BMI/hypertension, birth characteristics, infant age/cause of death. | Open web query, not new individual records. Counties below 250,000 population grouped as “Unidentified Counties”; 1–9 events suppressed. Could build a separate **county-year** analysis, or compare broad marginal patterns with main microdata. Do not claim these records are independent of the main CDC data. Export size depends on query, not a fixed archive. |
| [Census ACS 5-year API](https://www.census.gov/programs-surveys/acs/data/data-via-api.html) | County-year social, economic, housing and insurance measures (query-selected). | Open API, no fixed file size. Join to WONDER identified county/FIPS and suitable year, **not** to public individual CDC records. Beware 5-year rolling windows and ACS uncertainty. |
| [CDC/ATSDR Social Vulnerability Index](https://www.atsdr.cdc.gov/place-health/php/svi/svi-data-documentation-download.html) | County/tract social vulnerability measures and rankings, available as CSV for 2018, 2020, 2022 and other release years. | Public download; size not stated on provider page. Join to WONDER counties. [CDC cautions](https://www.atsdr.cdc.gov/place-health/php/svi/svi-data-documentation-download.html) against treating year-specific percentile ranks as a longitudinal scale; use underlying comparable measures where possible. |
| [HRSA Area Health Resources Files](https://data.hrsa.gov/data/download) | County health-workforce and facility supply, health status, population/economic/environmental measures, >6,000 variables. | Public with no usage limitation. Provider lists **22.6 MB** county CSV 2022–23, **22.5 MB** 2023–24, **22.7 MB** 2024–25. Join by FIPS/year to WONDER aggregates, not persons. Pick a few pre-specified provider variables; many variables have different reference years. |
| [CDC PRAMS](https://www.cdc.gov/prams/php/data-research/index.html) | Surveyed postpartum mothers: maternal experiences/behaviour, selected birth-certificate variables, BMI and survey weights. | As of provider page, **central ARF requests are not currently being processed**; site-by-site requests possible. No public ID for joining to main national linked file; outcome is postpartum survey, not a nationwide child-death cohort. Do not depend on this. |
| [NCHS fetal death public-use files](https://www.cdc.gov/nchs/data_access/VitalStatsOnline.htm) | Individual stillbirth/fetal-death records, a distinct outcome before live birth. | Open, e.g. provider lists 2024 file with cause of death at **1.9 MB**. Could motivate a separate perinatal-outcomes question but is neither extra predictors nor infant-death follow-up for the main cohort. |
| [PhysioNet PIC database](https://physionet.org/content/picdb/1.1.0/) | Chinese pediatric ICU admissions (2010–18), linked vital signs, labs, drugs, diagnoses, in-hospital mortality; includes NICU. | Credentialed access, training and data-use agreement; exact download size not publicly visible. Clinical hospital mortality is a different target/population from death in the first year among all live births. Useful only for a distinct hospital-risk thesis. |

## What is worth doing

1. Keep CDC cohort **individual-level** mortality analysis as the main thesis. Define prediction at birth versus during pregnancy; exclude later information accordingly. Train and test by birth year. Examine neonatal (<28 days) and post-neonatal (28–364 days) deaths separately, since mechanisms and feature timing differ. Compare calibration and precision–recall, not accuracy alone. [CDC 2023 cohort guide](https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Dataset_Documentation/DVS/period-cohort-linked/24PE23CO_linkedUG.pdf).
2. If an extra data chapter is wanted, construct a **separate ecological** county-year analysis from WONDER + HRSA AHRF + Census ACS or SVI. The unit becomes county-year. Report suppression, the exclusion of small counties, and ecological fallacy. It cannot be described as adding those variables to the CDC patient model.
3. Treat PRAMS, restricted NVSS and PIC as out of scope for the short March timeline. A larger ZIP is not a reason to add incompatible data.
